Estruturas de listas em HTML

Listas desordenadas

  • Item 1
  • Item 2
  • Item 3
  • Item 4
  • Subitens
    • sub 1
    • sub 2
    • sub 3

Listas Desordenadas coleções de itens apresentados com marcadores (como círculos, quadrados ou pontos) em vez de numeração, para indicar que a ordem dos itens não é importante. Em HTML, é necessário usar as tags ul e li, podendo, inclusive, criar sub-listas/sub-itens

Listas Ordenadas

  1. item
  2. item
  3. item

Listas Ordenadas coleções de itens sequenciais, onde a ordem é importante). Em HTML, essas listas utilizam das tag's ol e li.


  1. item
  2. item
  3. item

O tipo padrão de ordenação é o enumarado, porém, é possível alterar isso com adicionando 'type' na tag 'ol' e adicionar o tipo de ordenação desejado, por exemplo, "I" para romano ou "A" para letras.

Listas Descritivas são usadas para apresentar termos e suas respetivas descrições ou definições, criando um formato semelhante ao de um dicionário ou glossário. Em HTML, estas listas são criadas com as tags 'dl' para a lista, 'dt' para o termo e 'dd' para a descrição do termo.
